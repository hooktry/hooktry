# RESEARCH1 - Competitive Ontology Verification

Status: proposed research slice  
Added: 2026-10-04  
Source snapshots: S002, S003; selection universe expanded by S005 (200 products)

## Idea

Before turning the 102-product ontology into product decisions, verify it hands-on against a focused set of roughly 15-20 strategically important direct and adjacent products.

For each selected product, test the same primitives rather than relying on marketing copy:

`provision -> receive -> inspect -> persist -> replay/forward -> verify/sign -> wait/subscribe -> respond -> cleanup`

Record whether each ontology primitive is actually supported, how it behaves, and what object model the product exposes: Request, Event, Delivery, Attempt, Inbox, Fixture, Scenario, or equivalent.

## Why

S003 is lexical evidence from a broad market census, not verified feature coverage. This slice should separate:

- real table-stakes capabilities
- marketing-language artifacts
- rare but strategically important primitives
- Hooktry differentiators
- ontology terms that fail under hands-on use

## Output

Freeze the result as **S004 - Ontology Verification** and use it to update `02 Feature Taxonomy`, `03 Feature Coverage`, and later Hooktry product decisions.

S005 establishes a sufficiently broad 200-product selection universe. Keep S004 as a separate hands-on verification step; do not collapse it into breadth discovery.
