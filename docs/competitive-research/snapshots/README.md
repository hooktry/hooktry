## Correlation rules

1. Every new discovery pass gets a stable ID: `Pxx`.
2. Every frozen research snapshot gets a stable ID: `Sxxx`.
3. The Google Sheet tab `17 Discovery Passes` stores exact queries, results and the related snapshot.
4. Rows in `00 Market Map` carry `Discovery Pass`, `Discovery Query`, and `Discovery Family`.
5. Snapshots reference the passes that produced them.
6. If an old pass predates provenance logging, write `not captured (pre-provenance)` rather than reconstructing the query.
7. False positives and exclusions remain in the pass record so query quality can be compared over time.
